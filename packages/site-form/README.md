# Site Form

## Installation
`pnpm add @cloud-ru/uikit-product-site-form`

[Changelog](./CHANGELOG.md)

Форма сайта, собранная из реестра готовых полей. Поля задаются массивом `fields`: тип поля
определяет контрол, валидацию, подпись и ключ значения по умолчанию.

Форма работает на `react-hook-form` (peer-зависимость). Отправку, обработку ошибок сервера
и аналитику берет на себя потребитель через `onSubmit` и `events`.
Для показа серверных ошибок полей используйте `helpers.setFieldError` внутри `onSubmit`.

```tsx
<SiteForm
  layoutType={layoutType}
  fields={[
    { type: 'name', required: true },
    { type: 'email', required: true },
    { type: 'phone', required: true, size: 'full' },
    { type: 'comment', size: 'full' },
  ]}
  content={{ title: 'Оставьте заявку' }}
  onSubmit={async (values, { setFieldError, reset }) => {
    const { errors } = await send(values);

    if (errors) {
      Object.entries(errors).forEach(([name, message]) => {
        if (message) {
          setFieldError(name, message);
        }
      });
      return;
    }

    reset();
  }}
/>
```

Контролы формы (`Input`, `Checkbox`, `Submit` и др.) экспортируются отдельно для сборки
нестандартных форм — они должны рендериться внутри `FormProvider` из `react-hook-form`
и `SiteFormProvider`.

Для текстовых полей со своей подписью, подсказкой и ограничением длины используйте
`type: 'text'`. Состав бизнес-сценариев и преобразование значений для API остаются у потребителя:

```tsx
fields={[
  {
    type: 'text',
    name: 'projectInfo',
    label: 'Описание проекта',
    hint: 'Какую задачу решает проект?',
    showHintIcon: true,
    maxLength: 100,
    required: true,
    size: 'full',
  },
]}
```

`maxLength` проверяется при валидации, текст не обрезается. `analyticsName` переопределяет
имя в событии заполнения так же, как у готовых полей.
