# Price Summary

Компонент показывает предварительную стоимость ресурсов и тарифы оплаты за объём.

- **Ресурс** (`kind: 'entity'`) представляет SKU: виртуальную машину, хранилище, AI-модель и т. п. У ресурса могут быть параметры и скидка.
- **Параметр** описывает характеристику или часть цены ресурса. У параметров нет собственных SKU, доступности и покрытия грантами.
- Продукт рассчитывает и передаёт цены, скидки и итог. Компонент форматирует данные и не выполняет запросы.

## Установка

```bash
npm i @cloud-ru/uikit-product-price-summary
```

Компонент требует `@cloud-ru/uikit-product-locale` версии `^3.3.0`.

[История изменений](./CHANGELOG.md)

## Пример

Для заполнения покрытия грантами и доступности из результата расчёта передайте `calculatePriceData` и `id` ресурсов. Компонент сам выполняет сопоставление. Для фиксированных ресурсов, которых нет в результате расчёта, продукт может задать `coveredByGrants` непосредственно у ресурса в `invoice` или `usageInvoice`.

```tsx
import { CalculatePriceData, InvoiceDetails, PricePeriod, PriceSummary } from '@cloud-ru/uikit-product-price-summary';

const invoice: InvoiceDetails[] = [
  {
    title: 'Вычислительные ресурсы',
    items: [
      {
        kind: 'entity',
        id: 'sku-1',
        label: 'Виртуальная машина',
        quantity: 1,
        price: 2700,
        discount: { label: 'Скидка на ресурс', value: 300, percent: 10 },
        parameters: [
          { kind: 'parameter', label: '2 vCPU', price: 1800 },
          { kind: 'parameter', label: '4 ГБ RAM', price: 900 },
        ],
      },
      {
        kind: 'entity',
        id: 'sku-2',
        label: 'Диск',
        quantity: 1,
        price: 900,
        parameters: [
          {
            kind: 'parameter',
            label: 'SSD, 100 ГБ',
            price: 900,
            discount: { label: 'Скидка на параметр', value: 100, percent: 10 },
          },
        ],
      },
    ],
  },
];

const calculatePriceData: CalculatePriceData = {
  skuResults: [
    { skuId: 'sku-1', skuAvailability: true, coveredByGrants: true },
    { skuId: 'sku-2', skuAvailability: true, coveredByGrants: false },
  ],
};

<PriceSummary
  layoutType='desktop'
  period={PricePeriod.Month}
  invoice={invoice}
  calculatePriceData={calculatePriceData}
  basePrice={4000}
  value={3600}
/>;
```

При расчёте `price` ресурсов и параметров, а также итогового `value` нужно учитывать скидки. В примере цена до скидок — `4000`, скидки — `400`, итог — `3600`. Поле `discount` используется для отображения расшифровки; компонент не вычитает скидку из переданных цен повторно.

## Секции и шапка

| Свойство       | Содержимое                                                          | Состояние по умолчанию |
| -------------- | ------------------------------------------------------------------- | ---------------------- |
| `invoice`      | Ресурсы оплаты за время, включённые в `value`                       | Развёрнуто             |
| `usageInvoice` | Ресурсы с тарифами за единицу потребления, не включёнными в `value` | Свёрнуто               |

`invoiceExpandedDefault` и `usageExpandedDefault` задают начальное раскрытие секций. Подсказки заголовков можно заменить через `invoiceTooltip` и `usageTooltip`.

Шапка «Расчёт стоимости» с НДС отображается при наличии позиций в `invoice` или `usageInvoice`, включая недоступные по договору. При наличии `invoice` также показываются период, сумма и её расшифровка. Если передан только `usageInvoice`, под шапкой выводится разделитель и секция оплаты за объём, без суммы и переключателя периода.

Каждый элемент `InvoiceDetails` — категория с `title` и `items`. Категория объединяет ресурсы одного типа. В `items` передаются только ресурсы с `kind: 'entity'`; параметры, лимиты и строки скидок располагаются в `parameters` своего ресурса.

## Ресурсы, параметры и скидки

У ресурса `kind: 'entity'` задаются `label`, `id` для сопоставления с `calculatePriceData`, необязательные `quantity`, `price`, `coveredByGrants`, `discount` и `parameters`. Данные расчёта имеют приоритет над заданным покрытием. Числовой `quantity` отображается как `×N` сразу после названия. Разные конфигурации передаются отдельными ресурсами с `quantity: 1`.

В массиве `parameters` доступны три вида строк:

| `kind`      | Отображение                               | Основные поля                        |
| ----------- | ----------------------------------------- | ------------------------------------ |
| `parameter` | Серый текст, необязательная цена и скидка | `label`, `unit`, `price`, `discount` |
| `limit`     | Синий текст бесплатного лимита без цены   | `label`                              |
| `discount`  | Отдельная строка скидки                   | `discount`                           |

`unit` добавляет единицу после названия: например, «Хранение, 1 ГБ» или «Входящие токены, 1 млн». Для `usageInvoice` продукт передаёт тарифы за единицу потребления; они не пересчитываются при смене периода.

Скидку можно передать в `discount` ресурса или параметра — она отображается под соответствующей строкой. Для отдельной строки в `parameters` используйте `kind: 'discount'`:

```tsx
import { InvoiceParameterItem } from '@cloud-ru/uikit-product-price-summary';

const parameters: InvoiceParameterItem[] = [
  { kind: 'parameter', label: 'Хранение резервных копий', price: 450 },
  { kind: 'discount', discount: { label: 'Скидка по акции', value: 50, percent: 10 } },
];
```

Данные скидки:

| Поле          | Назначение                                                                 |
| ------------- | -------------------------------------------------------------------------- |
| `value`       | Размер скидки в рублях; отображается со знаком минус                       |
| `percent`     | Процент скидки для подписи                                                 |
| `label`       | Название скидки вместо стандартного «Скидка −N%»                           |
| `tooltip`     | Подсказка рядом с названием                                                |
| `valueFormat` | `amount` — сумма справа, `percent` — процент справа; по умолчанию `amount` |

В `price` ресурса и его платных параметров нужно передавать цены с учётом применимых скидок. Компонент отображает эти цены без пересчёта и не суммирует цены параметров.

`labelTooltip` и `labelMaxLines` управляют подсказкой и сокращением названия; `topDivider` и `bottomDivider` добавляют разделители. `hidePrice: true` скрывает цену строки.

## Период расчёта

`period` задаёт выбранный период, `onPeriodChanged` сообщает об изменении. Продукт управляет выбором и передаёт цены для нового периода.

`periodOptions` задаёт состав и порядок сегментов. По умолчанию это `[PricePeriod.Hour, PricePeriod.Month]`. Можно передать `[PricePeriod.Minute, PricePeriod.Month]`, `[PricePeriod.Month, PricePeriod.Year]` и другие сочетания `PricePeriod`. Выбранный `period` должен входить в массив; пустой массив скрывает контрол.

Начальный период выбирает продукт через `period`: например, час для AI Factory и Container Apps, месяц для остальных сервисов.

## Итоговая сумма и расшифровка

`value` принимает число или диапазон `{ min: number; max: number }`.

| `totalSumType` | Отображение числа |
| -------------- | ----------------- |
| `equal`        | Точная сумма      |
| `from`         | «от N ₽»          |
| `to`           | «до N ₽»          |

Для диапазона выводится «N — M ₽», а `totalSumType` не применяется. Ноль отображается как `0,00 ₽`; отсутствие `value` при наличии `invoice` — как `N/A`.

Под суммой доступны:

| Свойство         | Назначение                                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------------------------- |
| `hint`           | Подпись; при наличии `usageInvoice` по умолчанию «Без учёта оплаты за объём». Пустая строка скрывает подпись          |
| `scalingHint`    | Строка о масштабировании                                                                                              |
| `valueDelta`     | Изменение суммы: `{ value, type }`, где `type` — `increased` или `decreased`                                          |
| `basePrice`      | Цена конфигурации до применения скидок; при `priceChange` — цена конфигурации по умолчанию. Ноль также отображается   |
| `basePriceLabel` | Подпись базовой цены; по умолчанию «Конфигурация по умолчанию» при `priceChange` и «Базовая цена» в остальных случаях |
| `priceChange`    | Изменение стоимости: `{ value, percentage?, tooltip? }`                                                               |
| `discount`       | Общие скидки: `{ discounts: DiscountItem[] }`                                                                         |

Базовую цену передавайте через `basePrice`, общие скидки — через `discount.discounts`, итог с учётом скидок — через `value`:

```tsx
<PriceSummary
  layoutType='desktop'
  period={PricePeriod.Month}
  invoice={invoice}
  calculatePriceData={calculatePriceData}
  basePrice={4000}
  discount={{ discounts: [{ label: 'Общая скидка', value: 400, percent: 10 }] }}
  value={3600}
/>
```

В `priceChange.value` передаётся изменение со знаком; положительное значение выделяется красным, отрицательное оформляется как скидка. Если передан `percentage`, он выводится с тем же знаком. Например, `{ value: 5000, percentage: 10 }` отображается как `+5 000,00 ₽ (+10%)`. Необходимость показа изменения определяет продукт.

`titleTooltip` заменяет подсказку заголовка. Для дополнительных состояний подписи доступны `hintAppearance`, `showHintTooltip`, `hintTooltipText`, `showHintLink` и `hintLink`.

## Покрытие грантами

`coveredByGrants` можно задать у ресурса с `kind: 'entity'` в `invoice` или `usageInvoice`, например для фиксированной позиции, которой нет в результате расчёта.

Приоритет данных:

- `coveredByGrants: true` или `false` у сопоставленного SKU в `calculatePriceData.skuResults` перезаписывает значение ресурса, включая замену `true` на `false`.
- Если данные расчёта отсутствуют, SKU не найден или в его результате нет `coveredByGrants`, сохраняется значение ресурса.
- При `skuAvailability: false` ресурс переносится в блок недоступных, где метка покрытия скрыта независимо от заданного значения.

Параметры, бесплатные лимиты и строки скидок не имеют собственного покрытия и не влияют на статус ресурса.

Метка поднимается на самый высокий уровень с одинаковым известным статусом всех ресурсов: карточка → секция → категория. Если категория содержит ресурсы с разным покрытием, она разделяется на боксы по статусам. Параметры остаются со своим ресурсом. Неизвестный статус препятствует объединению; метка родителя не повторяется ниже.

При `loading` или `dataError` покрытие не отображается.

## Доступность SKU и данные расчёта

`calculatePriceData` содержит покрытие грантами и доступность SKU по данным расчётного сервиса. Данные имеют следующий формат:

```ts
type CalculatePriceData = {
  skuResults: SkuPriceResult[];
  allow?: boolean;
};

type SkuPriceResult = {
  skuId?: string;
  skuCode?: string;
  resourceSpecCode?: string;
  resourceSpecCodeId?: string;
  skuAvailability?: boolean;
  coveredByGrants?: boolean;
};
```

Чтобы связать ресурс с результатом расчёта:

1. Передайте результат расчёта в `calculatePriceData`.
2. Добавьте `id` ресурсу с `kind: 'entity'` в `invoice` или `usageInvoice`.
3. Значение `id` должно совпадать с `skuId`, `skuCode`, `resourceSpecCode` или `resourceSpecCodeId` из `skuResults`.

Параметрам `id` не передаётся. В сопоставленном результате `skuAvailability` определяет доступность по договору, а заданный `coveredByGrants` перезаписывает покрытие доступного ресурса. Компонент сам применяет эти признаки. Поле `allow` в отображении не используется.

Если данные расчёта отсутствуют, `skuResults` пуст или `id` не найден, сохраняется заданное у ресурса покрытие. Недоступность по договору компонент определяет только из `calculatePriceData`.

### Недоступные позиции

Ресурс, для которого в `calculatePriceData.skuResults` указано `skuAvailability: false`, удаляется из исходной категории и переносится вместе с параметрами в первый блок «Недоступно по договору» своей секции. Заголовок блока отображается красным тегом. Цены, скидки и метки покрытия внутри блока скрываются.

Недоступные ресурсы из всех категорий одной секции объединяются в один блок. В оплате за время и в оплате за объём такие блоки формируются независимо. Категория, в которой не осталось доступных ресурсов, удаляется из обычной детализации.

```tsx
<PriceSummary
  layoutType='desktop'
  period={PricePeriod.Month}
  value={200}
  invoice={[
    {
      title: 'Вычислительные ресурсы',
      items: [
        { id: 'sku-1', kind: 'entity', label: 'Первый ресурс', quantity: 1, price: 100 },
        { id: 'sku-2', kind: 'entity', label: 'Второй ресурс', quantity: 1, price: 100 },
        { id: 'sku-3', kind: 'entity', label: 'Третий ресурс', quantity: 1, price: 100 },
      ],
    },
  ]}
  calculatePriceData={{
    skuResults: [
      { skuCode: 'sku-1', skuAvailability: true, coveredByGrants: true },
      { skuCode: 'sku-2', skuAvailability: true, coveredByGrants: false },
      { skuCode: 'sku-3', skuAvailability: false },
    ],
  }}
/>
```

В этом примере `sku-1` помечается как покрытый грантом, `sku-2` — как не покрытый, а `sku-3` переносится в блок «Недоступно по договору» без цены. Итог для доступной конфигурации (`200`) передаёт продукт; компонент не вычитает стоимость недоступного ресурса из `value`.

## Промо и free tier

Порядок тегов: покрытие грантами → Free tier

`freeTier`: `true` показывает один общий синий тег «Free tier» вверху карточки, включая вариант только с `usageInvoice`. Подсказка по умолчанию: «Бесплатный тариф с фиксированными объемами ресурсов.»; `onFreeTierClick` задаёт действие по нажатию. У категорий и ресурсов этого признака нет
## Размеры, ссылка и состояния

Карточка занимает высоту по содержимому до `640px`. При превышении высоты нижняя часть прокручивается; шапка остаётся неподвижной внутри карточки. Это поведение сохраняется и при одном `usageInvoice`.

`docsLink: { href, text? }` добавляет ссылку внизу карточки. По умолчанию её текст — «Подробнее о тарифах и ценах».

`loading` показывает загрузку, `dataError` — ошибку получения данных, `onRetry` добавляет повторную попытку. `layoutType` управляет адаптивными подсказками.
